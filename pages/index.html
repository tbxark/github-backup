Quick start

From install to first backup

The configuration editor below generates a JSON file for the command line tool.

1

Install the command line tool

Install with Go, or build from the source repository.

go install github.com/tbxark/github-backup@latest
2

Create a configuration

Use the editor to set a GitHub owner and token, choose a backup provider, then download config.json. You can also import an existing JSON file to edit it.

3

Run a backup

Place the file where the command can read it. Without a cron expression, the tool runs once and exits.

github-backup -config config.json

Before you run

Keep your backup destination and deletion state file on persistent storage, especially for scheduled or container runs.

  • Local: Set a writable root directory. Repositories are stored as bare Git mirrors under root/owner/repo.
  • Gitea: Provide your server URL and API token in the backup provider settings.
  • Filters: Review unmatched repository behavior before enabling automatic deletion. The pre-delete count and state file help track repeated matches.
  • Secrets: Downloaded configuration files contain plain-text tokens. Store them securely.
